# ☕ Coffee Trading Game

เกมจำลองการเสนอราคาขายเมล็ดกาแฟแบบซ่อนราคา เล่นได้ 50 ทีม (คนจริงกับบอท ตั้งจำนวนได้) ทุกคนต่อ **Wi-Fi วงเดียวกัน** โดยให้โน้ตบุ๊กผู้จัดเป็นเซิร์ฟเวอร์ ไม่ต้องใช้อินเทอร์เน็ตระหว่างเล่น

## สิ่งที่ต้องมี

- โน้ตบุ๊กผู้จัด 1 เครื่อง ติดตั้ง **Node.js เวอร์ชัน 18 ขึ้นไป** (ดาวน์โหลดจาก https://nodejs.org ใช้อินเทอร์เน็ตแค่ตอนติดตั้งครั้งแรก)
- ผู้เล่นใช้มือถือหรือคอมที่มีเบราว์เซอร์ และต่อ Wi-Fi เดียวกับเครื่องผู้จัด
- ไม่ต้องรัน `npm install` เพราะเกมไม่มีแพ็กเกจเสริม

## เริ่มเกม

| ระบบ | วิธีเปิด |
|---|---|
| Windows | ดับเบิลคลิก `start-windows.bat` |
| macOS | ดับเบิลคลิก `start-mac.command` (ครั้งแรกอาจต้องคลิกขวา แล้วเลือก Open) |
| ทุกระบบ | เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์ `npm start` |

หน้าต่างเซิร์ฟเวอร์จะแสดงข้อมูลแบบนี้

```
หน้าผู้จัด (เปิดในเครื่องนี้):  http://localhost:3000/host
ผู้เล่นใน Wi-Fi เดียวกันเข้าที่:
   http://192.168.1.10:3000
รหัสผู้จัด: 4821
```

1. หน้าผู้จัดจะเปิดขึ้นมาเอง ถ้าไม่เปิด ให้เข้า `http://localhost:3000/host`
2. ตั้งค่าเกม: จำนวน **คนจริง** และ **บอท** (ค่าเริ่มต้นคือคนจริง 5 + บอท 45 = 50 ทีม) จากนั้นกด "บันทึกการตั้งค่า"
3. ให้ผู้เล่นเปิดลิงก์ `http://192.168.x.x:3000` ที่แสดงบนจอ แล้วใส่ชื่อทีม
4. กด **เริ่มเกม** ถ้าคนจริงเข้าไม่ครบ ระบบจะเติมที่นั่งที่ว่างด้วยบอท (ปิดตัวเลือกนี้ได้)

> **ถ้าผู้เล่นเข้าไม่ได้:** ตอนเปิดครั้งแรก Windows จะถามเรื่อง Firewall ให้กด "Allow" สำหรับ **Private network** และตรวจว่าทุกเครื่องต่อ Wi-Fi วงเดียวกัน Wi-Fi สาธารณะบางที่ (โรงแรม, มหาวิทยาลัย) บล็อกการเชื่อมต่อระหว่างเครื่อง ถ้าเจอแบบนี้ ให้เปิด Hotspot จากมือถือแล้วให้ทุกเครื่องต่อ Hotspot นั้นแทน

## วิธีเล่น (ฝั่งผู้เล่น)

แต่ละรอบใช้เวลา **5 นาที** (ผู้จัดปรับได้)

1. ดูผู้ซื้อ 6 รายของรอบ: แต่ละรายต้องการกาแฟชนิดไหน กี่กระสอบ ราคากลางเท่าไร
2. เสนอขายได้เฉพาะผู้ซื้อที่ต้องการกาแฟชนิดที่คุณมี โดยใส่ **จำนวน** และ **ราคาต่อกระสอบ** (มีปุ่มลัด 90%–150%)
3. กด **ส่งข้อเสนอ** แล้วยังแก้และกดส่งใหม่ได้จนหมดเวลา หรือกด **ไม่ขายรอบนี้** เพื่อเก็บสต๊อกไว้ขายรอบหลัง
4. เมื่อหมดเวลา หรือคนจริงทุกคนส่งแล้ว (ระบบจะนับถอยหลังอีก 10 วินาที) ระบบจะจับคู่ซื้อขายแล้วแสดงผล:
   - ขายได้กี่กระสอบ และถ้าขายไม่ได้เป็นเพราะอะไร
   - ได้คะแนนเพิ่มเท่าไร และตอนนี้อยู่อันดับที่เท่าไร
   - ภาพรวมตลาดของรอบ
5. ปุ่ม **คัดลอกข้อมูลให้ AI** จะสร้างสรุปกติกา สต๊อก ผลตลาดทุกรอบที่คุณเห็นได้ ประวัติข้อเสนอ และอันดับ เอาไปวางใน Claude หรือ ChatGPT เพื่อขอคำแนะนำได้
   - ถ้าปุ่มคัดลอกไม่ทำงานบนมือถือ ให้กดค้างที่กล่องข้อความเพื่อคัดลอกเอง
6. แท็บ **AI ที่ปรึกษา** คำนวณราคาและจำนวนที่แนะนำแบบออฟไลน์ แล้วกดปุ่มเดียวเพื่อใส่ค่าลงฟอร์มได้

## AI ที่ปรึกษา (ออฟไลน์ ใช้ทฤษฎีการเงิน)

AI ใช้เฉพาะข้อมูลที่ผู้เล่นคนนั้นเห็นได้จริง และไม่เห็นราคาของรอบที่ยังไม่ปิด ขั้นตอนคิดมีดังนี้

1. **EWMA** (Exponentially Weighted Moving Average แบบ RiskMetrics): หาค่าเฉลี่ยของ "ราคาตัดสิน" ของแต่ละชนิดกาแฟ ให้น้ำหนักรอบล่าสุดมากกว่ารอบเก่า
2. **Bayesian shrinkage**: เมื่อข้อมูลยังน้อย จะดึงค่าประมาณเข้าหาค่าเฉลี่ยรวมของตลาด เพื่อไม่ให้เชื่อข้อมูลไม่กี่จุดมากเกินไป
3. **Lognormal model**: คำนวณ P(ขายได้ที่ราคา p) = 1 − Φ((ln p − μ)/σ)
4. **Expected Value**: E[คะแนน] = P(ขายได้) × percentage_diff
5. **Mean–Variance / risk-adjusted utility**: U = E − γ·SD ซึ่ง γ เปลี่ยนตามโปรไฟล์ (ระวังความเสี่ยง / สมดุล / กล้าเสี่ยง)
6. **Inventory liquidation (TWAP)**: กระจายการขายสต๊อกตามจำนวนโอกาสที่คาดว่าจะเหลือ ถ้ารอบนี้ผู้ซื้อต้องการมากกว่าปกติจะแนะนำให้ขายเพิ่ม ถ้าทุกราคาให้ผลคาดหวังติดลบจะแนะนำให้รอ และในรอบสุดท้ายจะแนะนำให้ขายหมด

ทุกคำแนะนำแสดงโอกาสขายได้ คะแนนคาดหวัง ความเสี่ยง ระดับความมั่นใจ (ตามจำนวนข้อมูล) และเหตุผลประกอบ

## หน้าผู้จัด

- **ก่อนเริ่ม:** ตั้งค่าเกม, ดูรายชื่อผู้เล่นที่เข้าแล้ว, นำผู้เล่นออก
- **ระหว่างรอบ:** นาฬิกาตัวใหญ่ (ใช้ขึ้นโปรเจกเตอร์ได้), ปุ่มปิดรอบทันที / +1 นาที / หยุดชั่วคราว, สถานะว่าใครส่งแล้ว
- **หลังรอบ:** สรุปตลาด, กราฟคะแนนของคนจริง, ตารางอันดับ, ปุ่มเริ่มรอบถัดไป
- **ส่งออกข้อมูล:** ดาวน์โหลด CSV (ข้อเสนอทุกรายการ) และ JSON (สถานะเกมทั้งหมด)
- **คุมเกมจากเครื่องอื่น:** เปิด `http://192.168.x.x:3000/host?pin=รหัสผู้จัด`
- **บันทึกอัตโนมัติ:** เกมบันทึกไว้ใน `data/game-state.json` ถ้าเซิร์ฟเวอร์ปิดไปแล้วเปิดใหม่ จะเล่นต่อจากเดิม ถ้าต้องการเริ่มใหม่ให้ใช้ `npm run new` หรือกด "เริ่มเกมใหม่" ในหน้าผู้จัด
- **ผู้เล่นรีเฟรชหน้าเว็บ:** ระบบจำทีมไว้ในเบราว์เซอร์ จึงกลับเข้าทีมเดิมได้ทันที

## ข้อสมมติ (แก้ได้ทั้งหมดในหน้าตั้งค่า)

| เรื่อง | ค่าเริ่มต้น | สถานะ |
|---|---|---|
| จำนวนทีม / รอบ / ผู้ซื้อต่อรอบ | 50 / 15 / 6 | ผู้จัดเล่ามา |
| สินค้า | โรบัสต้าชนิดเดียว 7 เกรด A–G | ผู้จัดเล่ามา |
| ราคากลางแต่ละเกรด | A 1,400 · B 1,250 · C 1,100 · D 950 · E 800 · F 650 · G 500 บาท/กระสอบ | สมมติฐาน (แก้ในหน้าผู้จัด) |
| สต๊อกเริ่มต้น | 10 กระสอบ คละ 2 เกรด | สมมติฐาน |
| การจับคู่ | ผู้ซื้อเรียงราคาจากต่ำไปสูง ซื้อจากหลายทีมจนครบ ขายบางส่วนได้ | สมมติฐาน |
| ราคาขายจริง | เท่ากับราคาที่ยื่น (pay-as-bid) | สมมติฐาน |
| เพดานราคา / ราคาต่ำสุด | 150% / 50% ของราคากลาง | สมมติฐาน |
| ราคาเท่ากัน | จับฉลากด้วย seed (ผลซ้ำเดิมได้) | สมมติฐาน |
| สูตรคะแนน | B = Σ(percentage_diff × จำนวน) (เลือก A หรือ C ได้) | สมมติฐาน |
| ขายต่ำกว่าราคากลาง | คะแนนติดลบ (เลือกนับเป็น 0 ได้) | สมมติฐาน |
| ของเหลือตอนจบเกม | ไม่หักคะแนน (ตั้งค่าปรับได้) | สมมติฐาน |
| ความต้องการรวม | 90% ของสินค้ารวมทุกทีม | สมมติฐาน (ยังไม่ทราบนิยาม "90%" ของผู้จัด) |
| ข้อมูลที่เห็นหลังรอบ | ช่วงราคาที่ขายได้ของผู้ซื้อแต่ละราย | สมมติฐาน |

**บอท** มี 7 นิสัย ได้แก่ ตัดราคา, ราคากลางๆ, พรีเมียม, เก็บสต๊อก, ฉวยโอกาส, ปรับตัวตามตลาด และสุ่ม บอทตัดสินใจตอนเริ่มรอบจากข้อมูลที่เปิดเผยแล้วเท่านั้น จึงไม่เห็นราคาของใคร

> ผลจากเกมนี้เป็นการจำลองเพื่อฝึกและทำความเข้าใจกลไก **ไม่ใช่การคาดการณ์ผลการแข่งขันจริง**

## ทดสอบ

```
npm test
```

ชุดทดสอบครอบคลุม: การจับคู่ซื้อขาย, ไม่ขายเกินสต๊อก/ความต้องการ, เพดานราคา, สูตรคะแนน A/B/C, tie-break, seed เดิมได้ผลเดิม, จบเกมครบ 15 รอบ, บอทไม่เห็นราคา, มุมมองผู้เล่นไม่รั่วข้อมูล, AI ที่ปรึกษา และข้อความสรุปสำหรับ AI

## โครงสร้างไฟล์

```
server.js            เซิร์ฟเวอร์ HTTP + Server-Sent Events (ไม่มี dependency)
engine/game.js       กติกาเกม การจับคู่ สต๊อก รอบ มุมมองผู้เล่น/ผู้จัด
engine/scoring.js    สูตรคะแนน A/B/C
engine/bots.js       บอท 7 นิสัย
engine/market.js     ข้อมูลตลาดที่เปิดเผยได้
engine/advisor.js    AI ที่ปรึกษาเชิงสถิติ/การเงิน
engine/summary.js    ข้อความ "คัดลอกข้อมูลให้ AI"
engine/config.js     ค่าตั้งต้นและการตรวจค่า
public/              หน้าเว็บผู้เล่น (/) และผู้จัด (/host)
test/                ชุดทดสอบ
```

เปลี่ยนพอร์ตได้ด้วย `PORT=8080 npm start` และกำหนดรหัสผู้จัดเองได้ด้วย `HOST_PIN=1234`
